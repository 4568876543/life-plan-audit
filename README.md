# Life Plan Audit · 人生审计

> **不是问卷，是审计。**
> 一个给 AI Agent 用的 skill：把「我很迷茫」变成一份带数字、带动作、带放弃清单、**并且能活过第 15 天**的规划。

## 为什么做这个

市面上的「人生 100 问」有一个通病：

> **问完就结束了。**

用户答了一百个问题，得到一份「你是 INFP 型人格」式的报告，然后——什么都变了，也什么都没变。

更糟的是，其中一大部分会把人**越问越焦虑**。因为这类问卷默认了一个前提：

> 你答出来的关于自己的话，都是真的。

但事实是——**大部分人的迷茫，不是缺信息，是被一个从未验证过的自我判决锁死了。**

> 「我天生就坚持不了」
> 「我这性格做不了销售」
> 「我这辈子就这样了」
> 「我命里缺这个」

这些话听起来是「自我认知」，实际上是**未经检验的判决**。而所有规划工具都在这个判决之上继续盖楼。

**Life Plan Audit 做的第一件事，是把地基挖开检查一遍。**

做的第二件事，是承认：**想通了不等于做成了。** 所以它必须给出一个 14 天受控实验，并且要求第 14 天回来复盘。

## 和普通问卷的七个区别

| | 普通「人生 100 问」 | Life Plan Audit |
|---|---|---|
| **提问方式** | 一次抛 100 题 | 双模式：批量（≤12 题/轮）或深访（一次只问一题） |
| **是否读你的材料** | 不问，全靠现场答 | **先扫日记/简历/记录，已答的不再问** |
| **结论可信度** | 混在一起，分不清哪句真 | **每条结论标 L1 事实 / L2 自述 / L3 假设 / L4 已验证** |
| **遇到「我不行」** | 顺着安慰，或直接给建议 | **强制过七步证伪审计** |
| **遇到危机信号** | 继续问下一个问题 | **立即中止，切安全模式，给具体热线** |
| **输出物** | 性格报告 | **主线 + 支线 + 放弃清单 + 14 天实验卡** |
| **之后呢** | 结束 | **Life Baseline + 第 14 天复盘 + 90 天再审计** |

## v2.0 新增了什么

| 模块 | 解决的问题 |
|---|---|
| **安全协议**（`safety-protocol.md`） | 审计会碰到离婚、失业、疾病、丧失。原版有红旗表，但没有完整的处置动作。现在有：五个动作、语气对照、绝对不做的六件事 |
| **双模式访谈**（`interview-protocol.md`） | 原版只有「分轮批量」。但触及核心矛盾时，批量提问会让人敷衍。现在能切换成一次一问 |
| **自欺检测 + 目标归属三分** | 「这个目标是我的，还是被强加的？」——很多规划失败在这一步 |
| **分析三件套**（`analysis-framework.md`） | 八维差距地图 / 主系统节点（带维持回路）/ 无作为成本。让报告从「有文采」变成「可检验」 |
| **14 天受控实验 + Life Baseline** | 这是最大的增量。原版止于「明天的一个动作」，无法验证是否真的动了 |
| **假设-建议联动**（`evidence-rules.md`） | 每条重要建议挂一句「若假设不成立，建议改为」——承认自己可能错 |
| **完整版报告模板**（`report-template.md`） | 18 节结构 + 奥德赛三版本（当前路径 / 失效后谋生 / 不考虑钱和面子的理想） |

## 核心功能：七步证伪审计

这是本 skill 最有价值的部分，也是最不像「问卷」的部分。

**适用场景**：当你（或你的 AI）听到下面这类句子时——

- 「我天生就坚持不了」
- 「我性格不适合做 XX」
- 「我八字/星盘/MBTI 说我不能 XX」
- 「这几年全是失败，说明我不行」

**七步流程**：

1. **回溯审计** — 逐条标注：已被推翻 / 仍成立 / 无法验证
2. **事实反证** — 用客观事实反推，判据必须事前确立
3. **不可证伪性检验** — 成功怎么解释？失败怎么解释？都能解释 = 零信息量
4. **归因竞争** — 体系归因 vs 机制归因 vs 结构归因，比预测力
5. **设定证伪条件** — 什么结果出现，你就该承认结论错了？
6. **代价评估** — 接受这个结论，得到什么、失去什么
7. **翻译成条件** — 把「判决」变成「说明书」：什么条件下成立、什么条件下失效

**关键设计**：不去否定那套体系（会引发防御），而是**要求它在自己的体系里自洽**。

> 你说它准 —— 那请给出：什么情况下你会承认它不准？

详见 [`references/falsification-protocol.md`](references/falsification-protocol.md)，内含可直接使用的提示词模板。

## 14 天闭环：为什么它比「明天开始」有用

大部分规划死在第 3 天。不是因为人懒，是因为**计划按「最好的那天」设计，而人活在最差的那天**。

所以 v2.0 不布置计划，布置**实验**：

```
D0  接住结果，不做任何人生决定
D1  一个动作，目标是"拿到一个此前不知道的事实"
D2  小到低动机也能做完的一步
W1  最多两条规律（睡眠 / 记账 / 每天一个对外动作）
W2  只收数据，不追成果
D14 复盘九问 —— 没做完，是数据，不是失败
```

**关键设定**：实验卡上明写「全没做也算一种有效结果」。

否则人在第 3 天没做时，会判定「又失败了」，然后丢掉整份规划。

第 14 天复盘不问「为什么没坚持」，而问：**从「想」到「做」之间，发生了什么？**

归因表十种：计划太大 / 目标不认同 / 目标被强加 / 资源不够 / 恐惧 / 回避 / 没有结构 / 情绪负荷过高 / 环境变了 / 出现了更重要的真问题。

> 最后一条最重要：有时候没执行，是因为生活里出现了真问题。这不叫失败，叫优先级更新。

## 用法

### 场景一：完整审计

```
我想做一次人生审计。
我的日记在 /path/to/diary，简历在 /path/to/cv.pdf
```

AI 会先扫材料、出《已有事实清单》，再分三轮提问。材料多时会主动降到深访模式。

### 场景二：只做证伪

```
我总觉得自己"天生坚持不了"，
帮我用七步证伪审一遍这个判断。
（附上我持续做过的事：写日记 6 年、某系统连续运行 26 天……）
```

### 场景三：只算自由度

```
帮我算一下：如果收入归零，我能撑几个月？
收入 X，支出 A/B/C，存款 Y，房贷 Z（其中公积金冲抵 W）
```

### 场景四：14 天后回来复盘

```
我的 baseline 在 /path/to/LIFE-BASELINE-01.md
这 14 天我做了 X，没做 Y。开始复盘。
```

## 六条设计原则

1. **先挖，后问** — 已能从材料推出的，不许再问一遍
2. **双模式** — 批量铺面，深访挖矛盾。模式选错，分析全废
3. **证据分级** — L1 事实 / L2 自述 / L3 假设 / L4 已验证，禁止混用
4. **反宿命论闸门** — 任何「我不行」必须过七步
5. **输出决策，不输出人格** — 禁止「你适合做 XX」
6. **必须闭环** — 没有 baseline 和 14 天实验的规划，等于没做

## 红旗信号（会中断流程）

| 信号 | 动作 |
|---|---|
| 自杀/自伤意念（含「想过但不会做」） | 停止访谈 → 切温和语气 → 给 **12356** / **010-82951332** → 建议精神科 |
| 长期失眠 + 躯体化 | 先体检 + 睡眠门诊，规划延后 |
| 现金缓冲 < 3 个月 | 先解决现金流，不谈转型 |
| 近期重大丧失 < 6 个月 | 先哀悼，不做决策 |
| 答案开始模板化（「还行」「差不多」） | 切深访，或直接指出「你的回答在变短」 |

## 它不能做什么

- **不能替你决定**。它只给条件和代价，决定权永远在你
- **不能诊断心理疾病**。它只能识别红旗信号并建议就医
- **不能预测未来**。所有时间估算都是基于假设的区间，不是承诺
- **不能替代真实关系**。它是个工具，不是那个会在你住院时来看你的人
