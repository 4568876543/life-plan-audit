# 题库 / Question Bank

> **使用规则**：先扫用户材料，已能从材料推出的题**不要问**，改为陈述推断请他确认。
> 标记说明：`[可推断]` = 通常能从日记/简历/记录中提炼；`[必问]` = 只有本人知道，必须问。
> `[可跳过]` 规则：涉及隐私的题（收入明细、负债、体重与用药、关系细节），**用户可拒答**。拒答记为「空白」，不记为回避，不追问第三次。

---

## A 组｜事实底盘（≤10 题，必须最先答完）

> 这一组决定后面所有选项的空间。**没答完不进 B 组。**

| # | 问题 | 标记 | 为什么问 |
|---|---|---|---|
| A1 | 每月税后收入多少？构成（工资/绩效/副业）各占多少？ | [可推断] | 收入结构决定转型的容错空间 |
| A2 | 每月固定支出多少？逐项拆开（房贷/房租、教育、赡养、通勤、生活费） | [可推断] | 只有拆开才知道哪一项是刚性的 |
| A3 | 房贷余额、月供、剩余年限？其中多少由公积金冲抵？ | [可推断] | 公积金冲抵常被忽略，会大幅改变缓冲期 |
| A4 | 可动用现金多少？其中活期/理财/股票各多少？ | [必问] | 亏损后的净值才是真缓冲 |
| A5 | 有无负债？（信用卡/消费贷/亲友借款）月还款额？ | [必问] | 负债是唯一能让缓冲期瞬间归零的东西 |
| A6 | 配偶/前任是否有收入？抚养费/赡养费如何分担？ | [必问] | 单亲家庭的真实支出结构差异极大 |
| A7 | 孩子几岁？每月花多少？未来 3 年有没有大额支出（学费/保险/医疗）？ | [必问] | 大额支出会吃掉缓冲期 |
| A8 | 父母是否需要你赡养？从什么时候开始？预估多少？ | [必问] | 这是最容易被低估的隐性负债 |
| A9 | **如果收入明天归零，家里能撑几个月？** | 计算 | 这个数字决定所有选择的边界 |
| A10 | 每天工作几小时？其中多少是"真产出"，多少是"应付"？ | [必问] | 决定可投入副业的时间上限 |
| A11 | 每周有多少小时完全属于自己？ | [必问] | 可支配时间是所有计划的真实约束 |
| A12 | 最近体检有哪些异常？有无慢性病、长期用药？ | [可推断] | 健康是规划的第一约束，不是第二 |

**A 组输出物**：《自由度体检表》——缓冲月数、刚性支出占比、可支配小时数。

## B 组｜能量与耗竭（≤12 题）

> 这一组找的是"什么让你充电、什么让你断电"。**能力决定你能做什么，能量决定你能做多久。**

| # | 问题 | 标记 |
|---|---|---|
| B1 | 做什么事会让你忘记时间？（具体到场景，不是"工作"这种大词） | [必问] |
| B2 | 什么事做完让你感觉被抽干？ | [必问] |
| B3 | 现在的工作里，哪一部分你真心喜欢？ | [必问] |
| B4 | 哪一部分最厌恶？（越具体越好，是"开会"还是"被临时打断"？） | [必问] |
| B5 | 上次"忘了吃饭、时间飞快"是什么时候，在做什么？ | [必问] |
| B6 | 多久没有真正放松过了（不算刷手机）？ | [必问] |
| B7 | 一周有几次"醒来不想上班"？ | [必问] |
| B8 | 最近的快乐来源，具体到一件事。 | [必问] |
| B9 | 上次情绪崩溃是什么时候？因为什么？ | [可推断] |
| B10 | 你靠什么撑过最难的时候？ | [可推断] |
| B11 | 你持续得最久的一件事是什么？持续了多久？ | [可推断] |
| B12 | **你能持续的事，和持续不了的事，差别在哪？**（这是本组最重要的一题） | [必问] |

**B12 的判断框架**（AI 自己用，不要直接抛给用户）：
对比两类事的四个维度——① 反馈周期长短 ② 是否需要面对外部评价 ③ 失败是否有羞耻成本 ④ 是否有人支配过程。
**持续性差异通常不来自意志力，来自这四项的配置。**

## C 组｜能力与市场价值（≤10 题）

> 核心是区分**"会"和"能卖"**。

| # | 问题 | 标记 |
|---|---|---|
| C1 | 最有成就感的三件事？分别证明了你什么能力？ | [可推断] |
| C2 | 你的能力里，哪些**交付过**（有人用过、付过钱、上线过）？ | [可推断] |
| C3 | 哪些只是"会玩"，从没交付过？ | [必问] |
| C4 | 有没有人主动找你做过事？几次？付钱了吗？ | [可推断] |
| C5 | 你的能力里，哪一项别人短期学不会？ | [必问] |
| C6 | 如果明天开始接私活，你能接什么？报价多少？ | [必问] |
| C7 | 你的能力在招聘市场上对应哪些岗位？查过 JD 吗？ | [可推断] |
| C8 | 你投过简历吗？回应率多少？被拒的理由是什么？ | [可推断] |
| C9 | 行业里有几个人认识你的专业能力？（不是同事，是同行） | [必问] |
| C10 | 你被低估了吗？被谁低估？依据是什么？ | [必问] |

**关键判断**：把能力拆成四个因子——**能力 × 稀缺性 × 可验证性 × 议价位置**。
大多数"能力换不来钱"的案例，问题出在后两项接近零，而不是第一项。

| # | 问题 | 标记 |

| D2 | 钱 / 自由 / 被尊重 / 家庭 / 成就 / 安全——怎么排序？ | [必问] |
| D3 | 你最不能接受自己变成什么样的人？ | [必问] |
| D4 | 用一句话定义"成功"。 | [必问] |
| D5 | 用一句话定义"失败"。 | [必问] |
| D6 | 只能保一样：工作还是健康？ | [必问] |
| D7 | 你在意别人怎么看你吗？到什么程度？ | [必问] |
| D8 | 有没有"必须证明给他看"的人？是谁？ | [必问] |

## 出题纪律

1. **不按顺序念**。按用户当下最痛的点切入，答完一组再补下一组
2. **允许"跳过"**。明确告诉用户："这题不想答可以跳过，我们后面再回来"
3. **一次不超 12 题**。手机屏幕上下滑动超过三屏，答题率断崖下跌
4. **答完一组给一次反馈**。反馈必须包含：我听到的事实（L1）、我的推测（L3）、下一组要问什么
5. **同一问题不重复问**。如果用户材料里有，改成"我推断是 X，对吗"
