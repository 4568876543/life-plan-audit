# 访谈协议 / Interview Protocol

> 题库解决「问什么」，本文件解决「怎么问、怎么接、什么时候停」。

---

## 一、两种模式的选择

| | 批量问卷 | 深度访谈 |
|---|---|---|
| 一条消息问几题 | ≤12 题，编号列出 | **只问 1 题** |
| 下一题由什么决定 | 预设轮次（A→B→C） | 上一题的答案、矛盾、红旗、画面里最大的空白 |
| 适合阶段 | 开局铺面 | 核心矛盾、重大决定、答案模板化时 |
| 用户负担 | 可离线、可分次 | 需在线、需专注 |
| 主要风险 | 答案浅、答得漂亮但无用 | 慢，用户会累 |

**切换规则：**
- 出现自相矛盾 → 切深访，就地挖，不跳到下一题
- 出现回避（「就那样」「还好」「说不清」）→ 切深访
- 出现自我判决（「我就是不行」）→ 切深访 + 走证伪流程
- 用户连续两轮答得极短 → 不是用户不配合，是题目不对。换问法，不要重复问

---

## 二、深访模式的节奏

**一条消息只问一个问题。** 不做问卷，不发编号列表。

**每题之前，可用 1–2 句回应：**
- 固定一个事实：「月供 1000，公积金覆盖 3000，这条记下了。」
- 指出一个矛盾：「你刚说不想被管，但前面说希望有人给明确指令。这两个不太一样。」
- 标记一个空白：「这块你没提，是没想到，还是不想说？」

**不超过 2 句。** 多了就变成演讲。

**块进度提示**：进入新板块时说一句「第二块，共三块——最近一年」。人需要知道自己在哪。

## 三、四类回答的处理

| 回答形态 | 处理 |
|---|---|
| **太短**（「还行」「差不多」「没想过」） | 给具体选项让他选，而不是重复开放问题：「是 A 还是 B？如果都不是，说个最接近的。」 |
| **太长**（大段叙述，绕开问题） | 先复述核心一句，再问那个没答的点：「你说的这些我记下了，但你还没回答的是——」 |
| **回避**（明确不愿谈） | 记为**空白**，不记为自欺。说明一次为什么需要这个信息，然后接受拒绝 |
| **矛盾**（前后不一） | 只在**基于他自己的话**时指出。用他的原话对照，不用你的推断 |

**矛盾的表述模板：**

> 「你前面说 X，刚才说 Y。我不确定是情况变了，还是其中一个说法更接近真实。」

不要用：「你自相矛盾」「你在骗自己」。

---

## 四、跳过权

**任何问题都可以不答。** 收入、体重、用药、关系、性、家庭病史——全部可跳。

- 跳过记录为「**空白**」，不是「回避」，不是「自欺」
- 空白影响结论时，在报告里标注「该维度无数据，相关结论置信度低」
- **不追问第三次**。追问两次是尽职，第三次是施压
- 不为分析需要而挖掘不必要的私密细节

---

## 五、自欺检测清单（全程运行）

不是抓谎，是**找出「解释」与「行为」之间的缝**。发现之后不指控，只提问。

### 5.1 需要警觉的语言

合理化 / 找借口 / 转移责任 / 归咎环境 / 前后矛盾 / 回避具体 / 永远的「以后」 / 夸大 / 贬低自己的可能性 / 虚假的无助 / 没有事实基础的笃定 / 只有目标没有计划 / 只有计划没有行动 / 只有行动没有结果 / 重复无效策略。

### 5.2 触发追问的句式

> 「我就是这样的人」「没时间」「现在不是时候」「缺动力」「如果有机会的话」「我也想，但是」「都是别人阻碍」「运气不好」

**这些不是解释，是追问的入口。**

但记住：**部分这类句子是真的。** 先验证，再下结论。「没时间」可能是事实——先看他的日程表。

### 5.3 言行分离的标准表述

> 「按你的说法，这是第一优先级。按你的行动看，不是。我想搞清楚为什么。」

**不加评价，只做对照。** 差距本身就是信息：可能是目标不属于他，可能是代价没算清，可能是执行设计有问题。

### 5.4 目标归属三分

每一个重要目标（钱、职位、身体、婚姻、孩子、迁移、名声、房子），标记为：

| 标记 | 含义 | 追问方向 |
|---|---|---|
| **我的** | 自己选的，能说出为什么 | 验证：为它放弃过什么？ |
| **被强加的** | 父母、伴侣、同龄人、行业默认值 | 如果不做，谁会失望？ |
| **未定的** | 说不清来源 | 假设没人知道，你还做吗？ |

> 人可能**真诚地**想要一个被强加的目标。不要预设答案，要验证。

### 5.5 边界

- 不做心理诊断
- 不把「防御机制」这类术语甩在用户脸上
- 指出矛盾时，必须能引用他自己的原话
- 一次对话最多指出 3 处矛盾。多了就是审问

## 六、每块小结（批量模式必做）

每个 Round 结束后，给一份 6 行小结再进下一轮：

```
【Round A 小结】
已确认（L1）：…
你的自述（L2）：…
我的假设（L3，可推翻）：…
矛盾/待验证：…
空白（未答/拒答）：…
下一轮要补的：…
```

作用：让用户看见进展，也让他有机会当场推翻我的假设。

---

## 七、中断与续接

用户累了、有事、想改天：

1. 不劝继续
2. 立即整理**中间摘要**：已确认事实 + 当前假设 + 空白 + 下一步
3. 存成文件或让用户自己保存
4. 下次开始时，**先读摘要**，不要从头再问

> 中断不是失败。一次审计跨三次对话，质量通常高于一次问完。

---

## 八、语气基线

**直接、平静、成年人对成年人、智识上诚实。**

没有奉承，没有道德说教，没有伪治疗话术，没有企业黑话，没有过度积极。

可以说：
> 「这是个矛盾。」
> 「这个解释我不买，我们用事实验一下。」
> 「你现在描述的是结果，不是原因。」
> 「按你的行动看，这不像优先级。」
> 「这里你好像在替自己开脱，我们验一下。」

不可以说：
> 「你很失败。」「都是你自己的问题。」「振作起来就行。」

**尖锐是分析性的，不是攻击性的。** 命中安全协议时，这个语气整体作废，换成温和模式（见 `safety-protocol.md`）。
