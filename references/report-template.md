# 报告模板 / Report Template

> 两个版本：**简版**（9 节，个人自用，见 `plan-template.md` §七）、**完整版**（18 节，需要严谨性和可追溯性时用）。
>
> 无论哪版，**完整报告进文档，聊天里只给 5 行摘要**。

---

## 一、交付形态

### 1.1 聊天里给什么

```
主系统节点：{一句话}
最扎心的一条：{一句话}
优先级 №1：{一件事}
24 小时内：{一个动作}
下次检查：{日期}（+14 天）
```

**五行。不解释，不铺垫，不重复报告内容。** 用户想要更多会自己打开文档。

### 1.2 文档里给什么

完整报告，Markdown。文件名：`人生审计-{化名或主题}-{YYYYMMDD}.md`

存放建议：用户自己的日记/文档目录，**不要存在临时目录**——14 天后要回来读。

---

## 二、报告头部（必填）

```markdown
# {姓名/化名} 人生审计报告

生成时间：{YYYY-MM-DD HH:MM}
审计轮次：BASELINE 01
结论置信度：{高 / 中 / 低}
低置信度部分：{哪些结论缺数据，需要验证}
证据材料：{日记 N 篇 / 简历 / 绩效记录 / 对话}
```

**「结论置信度」必须写。** 不写就是暗示「我说的都对」，这是最危险的一种报告。

## 三、完整版 18 节结构

### 1. 执行摘要

- 一句话核心判断
- 推荐主线
- 备选路径
- 三个最大风险
- 30 天第一个动作

### 2. 前提假设与信息缺口

**这是全文可信度的地基。** 表格：

| 类型 | 内容 | 置信度 | 怎么验证 |
|---|---|---|---|
| 已知事实 | 月现金支出 5100 | 高 | 用户提供账单 |
| 假设 | 行业 3 年内不会回暖 | 中 | 查近 12 个月成交数据 |
| 未知 | 副业能否在 12 个月内过万 | 需验证 | 做 3 个付费客户 |

**必写一句**：「如果假设 X 不成立，那么建议 Y 应改为 Z。」

例：
> 如果「行业 3 年内不会回暖」不成立，那么「转行」的紧迫性下降，建议从「3 年转出」改为「2 年内在行业内换到有客户资产的位置」。

### 3. 个人画像

四个子块：
- **当前台阶**：硬技能、软技能、资源、能力边界（边界比能力更重要）
- **动机与能量**：驱动力、巅峰体验、价值观排序、能量模式（什么时候最强）
- **当前卡点**：焦虑的具体场景、试过的路径、失败的真实原因、限制性信念
- **未来画面**：3 年后一个理想的工作日长什么样（用时间表写）

### 4. 事实底盘

全部 L1，来自 `plan-template.md` §一：
现金流表 / 缓冲月数 / 时间预算 / 健康约束 / 家庭约束

### 5. 已推翻的判决

**这份报告最重要的部分。**

| 原判断（L2） | 审计结果 | 推翻依据（L1/L4） | 新表述（条件式） |
|---|---|---|---|
| 「缺乏持续力」 | 不成立 | 连续 3 年每月写日记；单个项目做满 14 个月 | 「在无外部反馈的事上易中断，在有客户反馈的事上能持续」 |

> 没有这一节，说明 P4 证伪没做，报告不合格。

### 6. 主系统节点

一句话 + 五段链 + 维持回路 + 干预点 + 验证信号。见 `analysis-framework.md` §二。

### 7. 八维差距地图

表格 + 三条读法结论。

### 8. 资源地图

十类资源，只记已发生的。

### 9. 能力与收入诊断

四因子打分（能力 × 稀缺性 × 可验证性 × 议价位置）+ 诊断结论。

### 10. 外部环境

- 慢变量（人口、利率、政策、行业周期）
- 产业链与利润池（钱在哪个环节）
- 人才供需
- **AI/自动化在任务级的替代性**（不要谈「AI 会不会取代我」，谈「我每天做的 8 件事里，哪几件会被替代」）
- 监管或平台依赖

**要求带来源。** 没有来源的趋势判断，一律降为假设。

### 11. 赛道 / 场景候选

| 候选方向 | 需求驱动 | 客户预算 | 与你匹配度 | 进入难度 | 置信度 |
|---|---|---|---|---|---|

| 具体场景 | 客户痛点 | 现在怎么凑合 | 为什么愿意付钱 | 你的切入点 |
|---|---|---|---|---|

### 12. 个人 SWOT

| 类型 | 证据 | 规划含义 |
|---|---|---|

**每格必须有证据。** 没有证据的 SWOT 是自我感觉。

### 13. 奥德赛计划：三个版本

| 版本 | 核心赌注 | 第一年动作 | 要建的能力 | 风险 | 验证信号 |
|---|---|---|---|---|---|
| **A 当前路径做到极致** | 在本行业/本岗位做到头部 | | | | |
| **B 当前路径失效后的谋生方案** | 如果行业没了，靠什么活 | | | | |
| **C 不考虑钱和面子的理想生活** | 纯粹想要的生活形态 | | | | |

**为什么要三个版本：**
- A 版给人安全感（不用马上推翻现在）
- B 版是保险（下行行业必须准备）
- C 版暴露真实偏好（往往和 A/B 差很远，差距本身就是信息）

**C 版的作用不是让人去实现它，是让人看见自己在为谁活着。**

### 14. 客户愿付钱的痛点（若涉及副业/创业）

每个机会写清：目标客户 / 痛点频率与强度 / 现在花多少钱凑合 / 为什么是现在 / 你的优势 / 第一个能触达的渠道 / 收费方式。

**判定标准：说不出「谁付钱、付多少、为什么现在付」，这个方向就不成立。**

### 15. 产品/服务原型与 MVP

| MVP 步骤 | 范围 | 成本/时间 | 成功指标 | 继续/停止规则 |
|---|---|---|---|---|

**MVP 必须比最终产品小得多。** 优先人工交付（concierge），不要先写代码。

### 16. 参与方式与变现阶梯

- 参与方式：受雇 / 独立顾问 / 内容 / 课程 / 产品 / 社群 / 合伙 / 投资 / 混合
- 变现阶梯：免费信号 → 低价 → 高价 → 可复制
- 获客渠道：熟人 / 陌生开发 / 平台 / 内容 / 合作
- 团队：先单人，再兼职，最后核心雇佣。**每个角色要说明为什么必要**

### 17. 路线图（30 / 90 / 180 天）

| 周期 | 目标 | 动作 | 指标 | 复核决策 |
|---|---|---|---|---|
| 30 天 | | | | 继续 / 调整 / 停 |
| 90 天 | | | | |
| 180 天 | | | | |

### 18. 风险、护栏与回退

| 风险 | 早期信号 | 缓解 | 回退方案 |
|---|---|---|---|

**必含三条护栏**：
1. 健康红线（恶化即回退）
2. 现金红线（缓冲 < N 个月即停手）
3. 关系红线（不能为了目标牺牲的那一样）

### 附：证据来源

列出所有 L1 材料的出处（文件路径、日期、条数）。

## 四、简版（9 节）结构

用于个人自用、快速迭代：

```
0. 一句话结论（主线）
1. 事实底盘
2. 已推翻的判决
3. 能力与收入诊断
4. 主线 + 三条支线
5. 放弃清单
6. 分期路线
7. 明天的动作
8. 风险预案
9. 回访节点
附：证据来源
```

简版**不能省**的三节：事实底盘、已推翻的判决、放弃清单。

## 五、写作规范

### 5.1 句式

**结论先行 → 前提 → 证据 → 推理 → 行动。**

### 5.2 禁止

| 禁止 | 原因 |
|---|---|
| 「你是一个……的人」 | 人格判决，不可证伪 |
| 「相信自己」「你一定可以」 | 口号，无信息量 |
| 「很多人都这样」 | 用普遍性消解个体问题的严重性 |
| 「建议寻求专业帮助」（不具体） | 等于没说，要给号码和科室 |
| 大量形容词（「深刻的」「彻底的」） | 情绪替代论证 |
| 单个成功案例当趋势证据 | 轶事不是证据 |

### 5.3 必须

| 必须 | 原因 |
|---|---|
| 每个结论挂证据等级 | 可追溯 |
| 每个建议挂条件 | 「在 X 条件下成立」 |
| 数字优先于形容 | 「月支出 5100」优于「开销不小」 |
| 说出不确定的部分 | 置信度低的地方明说 |
| 分清楚「他不能」和「他不愿」 | 两者的处方完全不同 |

### 5.4 「扎心的一条」怎么写

3–5 条，每条必须**引用他自己的原话或事实**，不羞辱、不戏剧化、不励志。

模板：
> 你说 X，但你的行动显示 Y。
> 问题看起来是 X，维持它的是 Y。
> 你高估了 X，低估了 Y。
> 如果不变，最可能的后果是 X。

> **尖锐是精确，不是姿态。**

## 六、交付前最后三问

1. 这份报告里，有几条是用户**读完会不舒服但无法反驳**的？（0 条 = 太软；>5 条 = 太狠）
2. 有没有一条建议，是他**明天就能做、且不需要任何人配合**的？
3. 如果三个月后他回来，我能不能一眼看出他有没有动？
