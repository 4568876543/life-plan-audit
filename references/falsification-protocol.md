# 反宿命论校验 / Falsification Protocol

> **本 skill 的核心差异点。任何"我不行 / 我天生 / 我命里 / 我运气差"的自我判决，都要过这一遍。**

---

## 一、什么时候用

| 触发信号 | 例子 |
|---|---|
| 用户给出**不可改变**的归因 | 「我八字缺火，天生不能持续」「我这性格就是做不了销售」 |
| 用户引用**宿命式金句** | 「假如我的能力让我一贫如洗，那我就活该」「性格决定命运」 |
| 用户用**单一负面事件**给自己下总判决 | 「这几年全是失败，说明我就是不行」 |
| 用户反复**求外部确定性**（算命、塔罗、MBTI、占星）并据此决策 | 「我算出来今年不宜动」 |
| 用户问「是不是我命里就这样」 | 直接触发 |

**不适用**：用户只是在表达情绪、需要一个出口时。那时候先陪着，不要立刻上审计——**审计是手术，不是安慰。**

---

## 二、为什么这套方法有效

**关键洞察**：不要去**否定**那套体系（会引发防御），而是**要求它在自己的体系里自洽**。

> 你说它准 —— 那请给出：什么情况下你会承认它不准？

任何无法回答这个问题的体系，无论多准，都只是**事后解释器**，不能用于决策。

**这个方法不攻击信仰，只检验预测力。** 用户可以继续信，但不能用它做决定。

---

## 三、三道锁（提示词里必须先立）

### 锁一：禁止把事实当作"体系准确"的证明

```
禁止把我提供的任何一条事实，用作"体系准确"的证明。
每条事实，你必须先给出至少一个非本体系的解释
（心理、机制、概率、环境、决策），然后才能讨论本体系的解释。
```

**作用**：防止对方把你的经历当成"验证命盘"的素材，越算越准、越算你越信。

### 锁二：可证伪性要求

```
为每个结论设定明确的证伪条件：
出现什么具体的、可观察的结果，你就应该承认这个结论错了？
如果给不出，请直接说"这个结论不可证伪"。
```

### 锁三：语言禁令

```
禁止出现"命该如此""顺其自然""接受它""这就是你的命"
"各人有各人的命""该来的会来"这类句子。
如必须说，请说明这句话为什么不能被替换成一个具体的行动建议。
```

## 四、七步流程

### Step 1 回溯审计

**要求**：逐条列出此前所有判断，标注三种状态。

| 状态 | 判据 |
|---|---|
| **已被推翻** | 有 L1 事实与之直接冲突 |
| **仍成立** | 有 L1 事实支持，且能给出证伪条件 |
| **无法验证** | 既无支持也无反驳的证据，或本身不可证伪 |

**禁止**：「大体上成立」「某种程度上对」——必须三选一。

---

### Step 2 事实反证

**做法**：抛出一组与该结论**直接矛盾**的客观事实（L1），要求解释。

**示例**（针对"缺乏持续性"）：
- 连续 N 年写日记，累计 M 个文件
- 某个系统连续运行 N 天零故障
- 某项习惯持续数月未断

**关键要求**：
> 如果解释是"这些不算真正的坚持"，请说明判据是什么，**且该判据必须是在看到这些事实之前就已经确立的，不能事后追加。**

这一句是整步的胜负手——它封死了"事后修改定义"的退路。

---

### Step 3 不可证伪性检验

**三个必问**：

1. 如果未来我**成功**了，你会怎么解读？（"大运到了" / "用神得力" / "原判断有误"）
2. 如果未来我**失败**了，你会怎么解读？（"命该如此" / "条件不足" / "方法问题"）
3. **如果成败都能被你的体系解释，这个结论对我还有多少信息量？**

**判定**：如果两个方向的解释都落在体系内部，**预测力为零**。

---

### Step 4 归因竞争

**做法**：列出至少三个竞争性解释，比较预测力。

| 类型 | 特征 | 预测力 |
|---|---|---|
| **A 体系归因** | 「你天生 XX」 | 模糊、不可检验 |
| **B 机制归因** | 「在 X 机制下你会断，在 Y 机制下你能持续」 | 具体、可检验 |
| **C 结构归因** | 「你选的战场需要 Z，而你没有 Z」 | 具体、可检验 |

**判据**：
> 用 A 预测我下一件事，和用 B、C 预测，**哪个能给出更具体、更可检验的预测？**

---

### Step 5 设定证伪条件

**要求对方为自己的结论设下限。**

**注意方向**：证伪条件不能设成"你能忍受多苦"，要设成"你能不能在真实场景里持续产出"。

| 错误方向 | 正确方向 |
|---|---|
| 「在消耗你的环境里撑 6 个月不崩溃」 | 「在面向外部评价的场景里持续交付 6 个月」 |
| 测的是忍耐力 | 测的是产出能力 |

**为什么重要**：错误方向的证伪条件会把结论引向"你只适合待在舒适区"，这恰恰是最需要打破的自我设限。

---

### Step 6 代价评估

**强迫对方说出宿命论的实际成本。**

```
如果我接受这个结论，用来解释我过去 N 年的一连串事件，
我会因此得到什么、失去什么？请具体列出来，两边都要写。
```

**典型输出**（这是让对方自己说出来，比你说有效十倍）：

| 得到 | 失去 |
|---|---|
| 心理上的即刻解脱 | 自我效能感 |
| 放弃挣扎的合理性 | 破局的机会 |
| 消除自责 | 真相（真正的原因被掩盖） |
| — | 对身边人的示范效应 |

---

### Step 7 翻译成条件

**把"判决"翻译成"说明书"。**

| 判决（禁止） | 说明书（要求） |
|---|---|
| 「你天生不能持续」 | 「你在 A 条件下能持续，在 B 条件下会断」 |
| 「你不适合做销售」 | 「你在有壳（产品/公司/报价）的情况下能卖，在无壳（以个人名义）的情况下会退缩」 |

**输出必须包含**：三个明天就能执行的具体动作。

**动作的设计标准**：
- 30 秒内能开始
- 不需要任何前置准备
- 失败成本为零
- 能立刻看到结果

## 五、对方常见回避话术 & 应对

| 回避 | 应对 |
|---|---|
| 「大运还没到」 | 「大运是条件还是结论？如果它能解释任何结果，那它就不是信息。」 |
| 「你理解得不对，命理不是这么看的」 | 「那请用你能接受的方式，重述这个结论的可证伪条件。」 |
| 「这些事只是巧合/个例」 | 「那请说明：什么比例的证据才足以让你修正结论？」 |
| 「你的意志可以改变，但底色不会变」 | 「'底色'的具体表现是什么？在什么情况下观察不到？」 |
| 「我说的是倾向，不是决定」 | 「好，那请把'倾向'翻译成'在什么条件下会显现、什么条件下不显现'。」 |
| 开始安慰、转移话题 | 「谢谢，但请先回答第五步：证伪条件是什么？」 |

**原则**：**不改口就不放行。** 但语气始终平和——目标是让它自洽，不是赢它。

## 六、判定：什么算通过

| 结果 | 判定 | 后续 |
|---|---|---|
| 对方承认原结论被推翻 | ✅ 通过 | 记录在案，作为后续规划的事实基础 |
| 对方给出明确证伪条件 | ✅ 通过 | 记录条件，设一个时间点回访 |
| 对方给不出证伪条件但坚持结论 | ⚠️ 部分通过 | **结论降级为"个人信念"，不进入决策依据** |
| 对方全程用回避话术 | ❌ 未通过 | 明确告知用户："这套体系在你这问题上没有预测力，可以当爱好，不能当依据" |

## 七、可直接使用的提示词模板

```
你此前给我的核心判断是：{原结论}。

我现在不需要你再解释一遍，我需要你做一次严格的自我审查。
请按下面七步回答，每一步都要给出具体内容。

【前置硬性规则，必须遵守】
禁止把我的任何一条事实，用作"{体系名}"准确的证明。
每一条事实，你必须先给出至少一个非{体系名}的解释
（心理、机制、概率、环境、决策），然后才能讨论{体系名}的解释。

【我的情况，全部真实】
{事实清单：基础信息 / 健康 / 事业 / 财务 / 持续行为记录 / 自我评价}

你之前的结论：{逐条列出}

【第一步：回溯审计】
逐条列出你此前的所有判断，标注：已被事实推翻 / 仍成立 / 无法验证。
不许用"大体上""某种程度上"。

【第二步：事实反证】
"{原结论}"怎么解释下面这些行为：{列举直接矛盾的事实}。
如果解释是"这些不算"，请说明判据，且判据必须在看到这些事实之前就已确立，
不能事后追加。

【第三步：不可证伪性检验】
1. 如果未来一年我成功了，你会怎么解读？
2. 如果我失败了，你会怎么解读？
3. 如果成败都能被你的体系解释，这个结论对我还有多少信息量？

【第四步：归因竞争】
关于"{问题}"，至少有三个竞争性解释：
A. {体系}归因：{原结论}
B. 机制归因：{反馈周期/外部评价/失败成本}
C. 结构归因：{战场所需的资源与我的实际拥有}

请判断哪个预测力最强。判据：哪个能给出更具体、更可检验的预测？

【第五步：设定证伪条件】
为"{原结论}"设定明确的证伪条件：出现什么具体的、可观察的结果，
你就应该承认这个结论错了？
如果给不出任何证伪条件，请直接说"这个结论不可证伪"。

【第六步：代价评估】
如果我接受这个结论，用它解释我过去 N 年的一连串事件，
我会得到什么、失去什么？两边都要写。

【第七步：翻译成条件】
如果你仍认为{原结论}成立，请把它从判决翻译成条件：
- 不要告诉我"我天生不能 X"
- 告诉我"我在什么条件下能 X，什么条件下会断"
- 给出三个我明天就能执行的具体动作
- 说明{体系内对应的概念}的解法，究竟是"认命"还是"主动改变"

【最后一条规则】
整篇回答禁止出现"命该如此""顺其自然""接受它""这就是你的命"
"各人有各人的命""该来的会来"这类句子。
如必须说，请说明这句话为什么不能被替换成一个具体的行动建议。
```

## 八、使用后的归档

**校验结果必须归档**，否则三个月后同一个判决会重新长回来。

归档格式：

```markdown
## {日期} 对"{原结论}"的证伪审计

- 原结论：
- 审计结果：已推翻 / 有证伪条件 / 不可证伪
- 推翻依据（L1 事实）：
- 证伪条件（如有）：
- 回访时间：
```

---

## 一句话

> **不是要证明"命是假的"，是要证明"这个判决不能替我做决定"。**
> **它可以继续当爱好，但不能再当驾照。**
