## 一、自由度体检（Round A 结束后立刻算）

### 1.1 现金流表

| 项目 | 月额 | 类型 |
|---|---|---|
| 房贷/房租 | | 刚性 |
| 其中公积金冲抵 | | 冲抵 |
| **房贷现金支出** | = 房贷 − 公积金 | **真实刚性** |
| 子女（托育/教育/杂费） | | 刚性 |
| 赡养父母 | | 刚性 |
| 通勤 | | 半刚性 |
| 生活（餐/水电/通讯） | | 可压缩 |
| 保险 | | 刚性 |
| 其他 | | — |
| **合计（现金）** | | |

### 1.2 缓冲期计算

```
可动用现金 = 现金存款 + 理财 + 股票市值 × 0.7（安全垫折算）
已知大额支出 = 未来 12 个月确定的大额（学费/保险/医疗/年节）
净缓冲 = 可动用现金 − 已知大额支出

缓冲月数（保守）= 净缓冲 ÷ 月现金支出
缓冲月数（乐观）= 净缓冲 ÷ (月现金支出 × 0.8)   ← 极端压缩
```

**判定标准**：

| 缓冲月数 | 含义 | 策略 |
|---|---|---|
| < 3 个月 | 危险区 | 先解决现金流，不谈转型 |
| 3–12 个月 | 紧张区 | 只能"边打工边试"，不能裸辞 |
| 12–24 个月 | 缓冲区 | 可以做 6–12 个月的试错 |
| **> 24 个月** | **从容区** | **转型不必赌，可以稳着来** |

> 关键提醒：**大多数人的紧迫感不是钱给的，是情绪给的。** 算完这个数，先让用户自己看一眼。

## 二、收入诊断公式

```
收入 = 能力 × 稀缺性 × 可验证性 × 议价位置
```

| 因子 | 判断标准 | 常见分值 |
|---|---|---|
| **能力** | 能不能做出来 | 0–100 |
| **稀缺性** | 会这个组合的人多不多 | 0–100 |
| **可验证性** | 有没有作品/案例/公开记录能证明 | **0–100（最常接近 0）** |
| **议价位置** | 有没有不依赖单一雇主的收入 | **0–100（最常接近 0）** |

**关键洞察**：
> **工资不是按能力定价的，是按岗位定价的。**
> 一个人在 A 岗位上做的事超出岗位要求的部分，是"免费溢出"，没有定价权。

**诊断结论模板**：
```
你的能力 {X} 分、稀缺性 {Y} 分，
但可验证性 {Z} 分、议价位置 {W} 分。
乘积里只要有一项接近零，整条链就是零。
你的问题不是能力低，是后两项接近零。
```

## 三、主线 + 三条支线

### 3.1 主线的写法

**要求**：一句话、可对外讲、不含"失败/遗憾/运气"。

```
用 {N} 年，把 {能力} 变成 {可持续的现金流形式}，
同时把 {风险} 分散到 {几个篮子}。
```

**示例**：
> 用 3 年把"行业认知 × 技术交付"做成能覆盖工资的副业；用 8 年让它成为主业并完成资产分散；55 岁前达到"不工作也不慌"的状态，且身边有人。

### 3.2 三条支线

**每条支线只能有一个验收指标。**

| 支线 | 目标 | 唯一验收指标 | 时间点 |
|---|---|---|---|
| **现金流** | 有能力自己养活自己 | 副业月入 ≥ {工资} | {日期} |
| **资产安全** | 钱不在一个篮子里 | 境外/多元资产 ≥ 总资产 {N}% | {日期} |
| **身体** | 不进医院 | {具体指标：睡眠/体重/BMI/某项体检值} | {日期} |
| **关系** | 老了有人来看你 | {2 个能说真话的人 / 重建亲密关系的可能} | 持续 |

> **第四条（关系）最容易被漏掉，但它决定晚年质量。钱能买护理，买不到有人愿意来。**

---

## 四、验收指标的设计原则

**禁止**：模糊目标（"提升能力""多赚钱""变得更好"）

**要求**：满足四条的才算验收指标

| 条件 | 反例 | 正例 |
|---|---|---|
| 可数 | "多写点东西" | "每周 1 篇，全年 52 篇" |
| 有截止 | "以后要做" | "2027-06-30 前" |
| 不看心情 | "感觉有进步" | "交付 3 个案例，其中 2 个收到尾款" |
| 失败可判定 | "尽量做到" | "52 篇中完成 ≥40 篇" |

## 五、放弃清单（最关键的部分）

**没有放弃，就没有主线。** 一个人卡住，通常不是因为不知道选哪条，是因为五条都想保。

模板：

| 放弃什么 | 为什么放弃 | 什么时候可以捡回来 |
|---|---|---|
| {目标1} | {代价 > 收益 的具体理由} | {条件} |
| {目标2} | … | … |

**同时必须写明"绝不能放弃的三样"**：
1. {底线1，通常是健康}
2. {底线2，通常是核心关系}
3. {底线3，通常是能赚钱的手艺}

## 六、"明天的一个动作"设计标准

**这是整份规划唯一能改变现实的部分。**

| 标准 | 说明 |
|---|---|
| **30 秒内能开始** | 需要"准备"的动作一定不会做 |
| **不需要前置条件** | 不用等钱、等人、等状态 |
| **失败成本为零** | 被拒绝也不损失任何东西 |
| **能立刻看到结果** | 有回应/没回应，当天就知道 |
| **指向主线** | 不是随便一件小事 |

**反例 vs 正例**：

| 反例 | 为什么不行 | 正例 |
|---|---|---|
| "我要开始做副业" | 太大，无法启动 | "给 X 发一条微信：你需要哪些功能？我列个清单" |
| "我要学英语" | 反馈周期太长 | "把今天要回的一封邮件，用英文写一遍" |
| "我要健身" | 需要长期坚持 | "今晚 22:30 把手机放到客厅充电" |
| "我要写公众号" | 需要选题、排版、发布 | "写 300 字：今天客户提的那个问题" |

## 八、路线图分期模板

| 阶段 | 时间 | 目标 | 验收标准 | 禁忌 |
|---|---|---|---|---|
| **① 止血 / 稳底盘** | 0–90 天 | 睡眠、现金流、不新增战场 | 睡眠达标、无新增负债 | 不做重大决定 |
| **② 造窗口** | 3–18 个月 | 做出 3 个可展示的交付案例 | 3 个案例 + 1 份案例文档 | 不同时开 3 个方向 |
| **③ 低飞** | 18–36 个月 | 换到能积累自己客户的位置 | 副业 ≥ 工资 50% | 不裸辞 |
| **④ 独立** | 3–8 年 | 自营收入 ≥ 工资 1.5 倍 | 连续 6 个月达标 | 不 all-in 单一客户 |

**分期铁律**：

1. **上一阶段验收没达成，不进入下一阶段**
2. **每个阶段只允许一个主目标**
3. **任何阶段，健康指标恶化 → 立刻回退到上一阶段**

## 九、回访机制

规划交付时，必须同时给出回访节点：

| 节点 | 检查什么 |
|---|---|
| 30 天 | "明天的一个动作"做了没有？没做的真实原因是什么？ |
| 90 天 | 第一阶段验收指标达成率？ |
| 180 天 | 证伪条件是否触发？（如果触发了，原判决要重新评估） |
| 1 年 | 三条支线各自的进度；主线是否还成立 |

**回访只问三个问题，不重开一轮 100 题。**

## 十、14 天受控实验（本 skill 的闭环核心）

> **规划最大的谎言，是让人以为「想清楚了」等于「做成了」。**

审计结束时，人处在一种「刚被看透、情绪高涨、准备重新做人」的状态。**这个状态下的决心，存活率极低。**

所以不要在这时布置「每天 3 小时」的计划。布置一个**受控实验**：目标不是改变人生，是**收集关于自己的数据**。

### 10.1 设计原则

| 原则 | 说明 |
|---|---|
| **实验目标 = 取数据** | 不是「养成习惯」，是「看看会发生什么」 |
| **低动机也能完成** | 用「最差的一天」做设计基准，不是「最好的一天」 |
| **一次只测一个变量** | 同时改三件事，结果无法归因 |
| **有明确观测点** | 每天 1 个数或 1 句话，不写日记 |
| **失败也有信息量** | 没做，本身就是最重要的数据（见 12 节） |

### 10.2 五天节奏

```
D0（当天）  接住结果，不做决定
            ├─ 保存报告
            ├─ 用自己的话写下最扎心的一句
            └─ 只做一件事：把报告存到会再打开的地方
            ★ 禁止在这一天做任何人生决定

D1（第 2 天）第一次接触现实
            └─ 一个与主系统节点直接相关的小动作，目的是获取新信息
               例：翻出真实账单 / 查一个岗位的真实要求 / 给一个人发消息
               ★ 标准是「拿到一个此前不知道的事实」，不是「解决一个问题」

D2（第 3 天）第一个可控步骤
            └─ 小到低动机状态下也能做完
               例：写 300 字 / 打一个电话 / 填一张表的前三行

W1（第 4–7 天）第一次行为变化
            └─ 只在真正需要规律的地方设规律：睡眠、记账、每天一个对外动作
               ★ 最多设 2 条，多了必然全崩

W2（第 8–14 天）第一批数据
            └─ 不追求成果，追求「有没有产生可比较的记录」
               第 14 天带着记录回来做复盘
```

### 10.3 实验卡（交付时一并给出）

```markdown
## 14 天实验卡

**唯一变量**：{这 14 天只改的一件事}
**假设**：{我认为做了 X，会导致 Y}
**每天记录**：{一个数字或一句话，例如「今天有没有发出 1 条对外消息：有/没有」}
**判定线**：
  - 14 天内完成 ≥ {N} 天 → 假设初步成立，进入下一阶段
  - 完成 < {N} 天 → 不视为失败，进入归因（见复盘九问 Q3）
**如果全没做**：说明这件事的阻力被严重低估，需要重新设计或重新审视目标归属
```

> **关键**：实验卡上必须写清「全没做」也算一种有效结果。否则用户在第 3 天没做时，会直接放弃整个规划——因为他会觉得「又失败了」。

## 十一、LIFE BASELINE（基线档案）

**第一次审计必须落一份基线。** 没有基线，第二次审计无法比较，而人是会忘记自己起点在哪的。

存成独立文件，和报告放一起。提醒用户：**这份文件含高度个人信息，自行决定存放位置。**


## 十二、14 天复盘（第 14 天必做）

### 12.1 复盘九问

先读 baseline，再让用户回答。**这是「一条消息只问一个问题」规则的唯一例外——可以一次给出九问，让他一次答完。**

1. 我做了什么？
2. 我没做什么？
3. 为什么没做？
4. 什么变了？
5. 什么比想象中难？
6. 什么比想象中容易？
7. 我对自己发现了什么？
8. 我打算继续做什么？
9. 计划里需要改什么？

然后**逐条拆**，每条对着 baseline 比。

### 12.2 未完成 = 数据，不是失败

**绝对不要说「没关系，再试一次」。** 这句话关闭了分析。

要问的是：**从「想」到「做」之间，发生了什么？**

| 归因 | 追问方向 | 处方 |
|---|---|---|
| 计划太大 | 哪一步卡住了？ | 砍到 1/5 |
| 目标不认同 | 做的时候有抵触吗？ | 回到目标归属三分 |
| 目标是被强加的 | 不做，谁会失望？ | 可能要换目标，不是换方法 |
| 资源不够 | 缺什么？能用钱/时间换吗？ | 补资源或降标准 |
| 恐惧 | 怕的具体是什么结果？ | 设计一个失败成本为零的版本 |
| 回避 | 每次想做时，先做的是什么？ | 找出替代行为 |
| 没有结构 | 有没有固定的时间地点？ | 绑定到已有习惯 |
| 情绪负荷过高 | 做的时候身体什么感觉？ | 降低情绪暴露度 |
| 环境变了 | 具体变在哪？ | 重设，不算失败 |
| 出现了更重要的真问题 | 是什么？ | **重新审计**，旧计划作废 |

> **最后一行最重要**：有时候没执行，是因为生活里出现了真问题。这不叫失败，叫优先级更新。

### 12.3 复盘输出

```
【14 天复盘】
计划 → 实际：{完成 N/14 天}
归因：{上表命中哪一条}
新发现：{baseline 里没有的信息}
计划修订：{保留 / 砍半 / 换目标}
下一步：{一个新的 14 天变量}
```

## 十三、重复周期

| 节点 | 做什么 | 产出 |
|---|---|---|
| **+14 天** | 短复盘（十二节） | 计划修订 |
| **+30 天** | 进度检查：验收指标动了没有 | 一次 8 行状态 |
| **+60–90 天** | 完整比较审计 | **LIFE BASELINE 02** |

比较链固定为：**计划 → 行动 → 结果 → 新情况 → 新结论**。

**必须展示差距地图的分数变化。** 人不记得自己起点在哪，会误以为「一直就这样」。把两列分数并排放，是最有说服力的证据。

## 十四、交付清单（自查）

审计交付时，以下八项缺任何一项，视为未完成：

- [ ] 事实底盘（现金流 + 缓冲月数）
- [ ] 已推翻的判决（至少 1 条，否则 P4 没做）
- [ ] 主系统节点（1–2 个，带回路）
- [ ] 八维差距地图
- [ ] 主线 + 支线 + 唯一验收指标
- [ ] 放弃清单 + 绝不能放弃的三样
- [ ] 14 天实验卡
- [ ] LIFE BASELINE 01 + 下次检查日期
