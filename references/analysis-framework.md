# 分析框架 / Analysis Framework

> 访谈拿到的是原料。这一层决定报告是「有洞察」还是「有文采」。

产出三件套：**差距地图 → 主系统节点 → 无作为成本**。三样缺一样，结论就站不住。

---

## 一、八维差距地图

### 1.1 打分锚点

| 分 | 含义 | 事实特征 |
|---|---|---|
| 1–3 | 该维度处于危机，正在拖垮其他维度 | 有明确的失控事件、医疗记录、债务违约、关系破裂 |
| 4–6 | 能忍，但有明显不满 | 能维持，但持续消耗；有反复抱怨但没有行动 |
| 7–8 | 整体良好 | 有具体进展、有可复述的成果 |
| 9–10 | 满意，且有事实支撑 | 有第三方认可、有量化结果、当事人不焦虑 |

**打分的三条纪律：**

1. **每个分数必须挂一个事实**。挂不上，就是没数据
2. 没数据的维度写「**无数据**」，不写 5 分。5 分不是中性，是伪造
3. 用户自评和事实依据分两列。**差距本身就是发现**

### 1.2 表格

| 维度 | 自评（1–10） | 事实依据 | 事实对应的分 | 期望状态 | 差距 | 优先级 |
|---|---|---|---|---|---|---|
| 健康 | | | | | | |
| 金钱 | | | | | | |
| 工作 | | | | | | |
| 关系 | | | | | | |
| 家庭 | | | | | | |
| 自由 | | | | | | |
| 社交 | | | | | | |
| 成长 | | | | | | |

**读法：**
- 自评高于事实分 → 该维度被低估了严重性
- 自评低于事实分 → 该维度是自我否定的重灾区（往往与 P4 证伪联动）
- 差距大但优先级低 → 说明当事人已经不指望它了，这也是信息

### 1.3 常见错误

- 八个维度全打 5–6 分 → 用户在敷衍，回访谈补事实
- 只填「工作」和「金钱」→ 这个人当前被生存问题占满，其余维度要主动问
- 所有差距都很小 → 要么数据假，要么标准太低，追问「如果满分是什么样」

## 二、主系统节点

**不要给 20 个问题。找 1–2 个系统性成因。**

### 2.1 五段链

```
症状 → 直接原因 → 后果 → 次级后果 → 维持回路
```

**维持回路是关键。** 没有回路，就只是一个问题；有回路，才是一个会自己长大的问题。

### 2.2 示例

**示例 A（收入型）**
> 收入不稳 → 持续焦虑 → 回避谈钱和报价 → 客户流失 → 收入更不稳

节点不在「焦虑」，在「回避报价」。解决焦虑没用，解决报价动作才有用。

**示例 B（能力型）**
> 自我判决「我不行」→ 不做 → 没有新证据 → 判决被"验证" → 更确信自己不行

节点不在「自信」，在「缺少一次低成本的反证实验」。

**示例 C（时间型）**
> 白天被工作占满 → 晚上报复性熬夜 → 睡不够 → 白天效率低 → 工作占更多时间

节点不在「自律」，在「白天的失控感」。

### 2.3 判定标准

一个合格的主系统节点要同时满足：

1. **能解释至少 3 个维度的现状**（不只影响一个方面）
2. **有可操作的干预点**（不是「原生家庭」这种无法动手的东西）
3. **干预后 30 天内能观察到变化**（否则无法验证）
4. **当事人自己认**（他不认的节点，写得再对也不会被执行）

### 2.4 输出格式

```
主系统节点：<一句话>
维持回路：A → B → C → A
为什么是它：它同时解释了 <维度1/维度2/维度3>
干预点：<一个具体动作>
验证信号：<30 天内能看到什么>
```

## 三、资源地图

**不要让人只透过缺口看自己。但也不要把幻想记成资源。**

| 类别 | 判断标准 | 记录方式 |
|---|---|---|
| 硬技能 | 有人付过钱，或交付过成品 | 写成果，不写「会一点」 |
| 软技能 | 有具体场景证明 | 「能在 3 人会议上推动决策」 |
| 资金 | 可动用现金 + 可变现资产 | 写数字和缓冲月数 |
| 时间 | 每周可自由支配小时数 | 写真实数字，不写「应该有空」 |
| 关系 | 能直接打电话的人 | 写「能求他做什么」，不写「认识谁」 |
| 声誉 | 有第三方背书的记录 | 写可查证的 |
| 身体 | 睡眠、精力、慢性病 | 写限制，也写余量 |
| 学习能力 | 最近 12 个月学会的东西 | 写具体技能，不写「学习能力强」 |
| 过往成果 | 做成过的事（含失败的项目里做成的部分） | **失败项目里的成功部分最容易被漏掉** |
| 情绪资源 | 谁能在崩溃时接住你 | 写名字或角色 |

**规则：只记「已经发生过的」。** 「我如果认真做也能……」不进资源地图，进假设清单。

## 四、无作为成本

> 这不是预测，是**情景评估**。用「最可能的情况是」「如果趋势延续」，不用「你一定会」。

### 4.1 三个时间点

| 时间 | 要回答的问题 |
|---|---|
| 3 个月 | 什么会先坏？身体、现金流、关系、还是动力？ |
| 1 年 | 哪些选项会永久关闭？（年龄、行业窗口、健康、关系） |
| 5 年 | 那时的日常是什么样？用一天的时间表来描述，不用形容词 |

### 4.2 写法要求

**不合格：**「再不改变，你会越来越焦虑。」

**合格：**
> 5 年后最可能的日常：早上 7 点起，通勤 40 分钟，做和现在几乎一样的事，工资涨幅低于通胀。你会更熟练，也更清楚自己不会再有变化。身体上，如果睡眠问题没处理，大概率已经有一次因疲劳导致的健康事件。这个描述里没有灾难，只有「安静地停在原地」——而这恰恰是最难被察觉的成本。

**要点：**
- 用**具体场景**，不用情绪词
- 分清「会发生的」和「可能发生的」
- 不恐吓，也不淡化。**安静地停在原地，本身就是成本**

### 4.3 反向成本

也要算「改变的成本」：钱、时间、关系损耗、失败后的退路。

只算一边的账，是不诚实。

## 五、过度拟合检查

分析完成后，问四个问题：

1. 我的建议里，有多少是围绕**他现在这份工作**展开的？超过一半，就是拟合
2. 有没有一条路是他**现在没想过**、但证据支持的？
3. 我是不是把「他不愿意」错判成「他不能」？
4. 如果把他的行业整个删掉，这份报告还剩下什么？

第 4 题答不出来，说明报告的价值依附于一个正在下行的行业。

## 六、分析质量自检

| 检查项 | 不通过的表现 |
|---|---|
| 每个结论有证据等级 | 出现「你是一个……的人」 |
| 主系统节点只有 1–2 个 | 列了 8 个问题 |
| 差距地图每格有事实 | 有一半格子是空的或填 5 |
| 资源地图里没有幻想 | 出现「有潜力」「人脉广」 |
| 无作为成本用了情景语言 | 出现「你一定会」 |
| 给了相邻路径 | 所有路径都指向「在当前行业做得更好」 |
